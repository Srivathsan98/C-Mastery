# Question
What is the purpose of the compilation pipeline? List and explain each stage: preprocessing, compilation, assembly, and linking.

# Answer
- **Preprocessing** – Handles macros, includes, and conditional compilation, producing expanded source code.
- **Compilation** – Checks syntax and semantics, then converts the code into assembly.
- **Assembly** – Translates assembly into machine code, generating object files.
- **Linking** – Combines object files and libraries, resolving symbols to produce the final executable.
